# Last Time

A simple iOS app to track when you last did something. Never forget when you last watered your plants, changed your sheets, or took your medication.

## Features

- Track any recurring task or activity
- See how long it's been since you last completed each task
- Pin important tasks to the top
- Set custom repeat intervals and get notifications
- Widgets for your home screen
- iCloud sync across all your devices
- Dark mode support

## Requirements

- iOS 17.0+
- Xcode 15.0+

## Getting Started

1. Clone the repo
2. Open `Last Time.xcodeproj` in Xcode
3. Select your development team in Signing & Capabilities
4. Build and run

## Setup

The app uses iCloud sync with CloudKit. Make sure to:
- Add your development team in the project settings
- Enable iCloud capability
- Configure the CloudKit container in App Store Connect

## Privacy

All data is stored locally on your device and synced via iCloud. No data is collected or shared with third parties.
